# تعليمات الوكلاء

## القاعدة الأساسية

أي Agent يعمل على Cutra يجب أن يبدأ من هذا المجلد، ولا يعتمد على ذاكرة محادثة قديمة بدل الملفات.

## Codex

Codex مسؤول عن:

- فحص المستودع قبل التعديل.
- تنفيذ المهام التقنية.
- تشغيل الاختبارات والتحقق.
- تحديث الوثائق عند تغيير المعمارية أو workflow.
- الالتزام بـ SOLID.
- عدم إضافة dependency بدون بحث وموافقة.

## Antigravity

Antigravity مسؤول عن:

- مراجعة الخطة وتجربة المستخدم.
- توضيح المتطلبات قبل التنفيذ.
- مراجعة تسلسل المهام.
- كشف الفجوات في workflow أو المنتج.
- مساعدة Codex في handoff واضح.

## مالك المشروع

مالك المشروع يحسم:

- قبول المكتبات الجديدة.
- قرارات المنتج.
- API behavior غير الواضح.
- منصة الإطلاق الأولى.
- أي تغيير معماري كبير.

## قواعد العمل

- استخدم task IDs من `TASKS.md`.
- سجل القرارات في `DECISIONS.md`.
- راجع `SYNC_MATRIX.md` إذا كانت المهمة تمس integration أو testing أو generated code.
- لا تكتب كودًا مخصصًا لحل معروف قبل البحث عن مكتبة مستقرة.
