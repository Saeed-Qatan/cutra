# الأدوار والمسؤوليات

## Codex

ينفذ العمل التقني:

- فحص المشروع.
- تعديل الكود.
- إضافة الاختبارات.
- تشغيل التحقق.
- تحديث الوثائق التقنية.

## Antigravity

يراجع المنتج والتخطيط:

- وضوح flow.
- قابلية الاستخدام.
- تسلسل المهام.
- المخاطر والفجوات.

## Human Owner

يحسم:

- المكتبات الجديدة.
- قرارات المنتج.
- API behavior غير الواضح.
- أولويات المراحل.
- الإطلاق.

## التعاون

1. يتم اختيار task ID.
2. يتم تحديد المخرجات.
3. Codex ينفذ.
4. Antigravity يراجع عند الحاجة.
5. يتم تحديث `DECISIONS.md` و`TASKS.md`.

## عند الخلاف

- ثم ملفات `agents/`.
- ثم حقائق المستودع.
